# pawtrol

바탕화면 작업 표시줄 위에서 지내는 도트 고양이입니다. Claude Code 세션과 PC 상태를 말풍선과 동작으로 알려 줍니다.

## 하는 일

| 상황 | 고양이 |
|---|---|
| Claude 응답이 끝남 | 폴짝 뛰고 "「세션 제목」 작업이 끝난 것 같아요" 말풍선 |
| Claude 가 권한 승인 · 입력을 기다림 | "「세션 제목」 세션이 기다리고 있어요" 말풍선 |
| Claude 가 일하는 중 | 노트북을 두드림 |
| CPU 85% 이상이 10초 넘게 이어짐 | 노트북을 더 빠르게 두드리고 땀방울 |
| RAM 90% 이상 | 반쯤 감긴 눈으로 느릿느릿 |
| 오래 손대지 않음(5분) | 식빵 자세로 잠(Zzz) |

알림이 여러 건이면 덮지 않고 쌓이며 "다음"으로 넘겨 봅니다. 같은 세션 알림은 하나로 합칩니다.
세션 알림 글을 누르면 Claude 앱이 그 세션을 엽니다. Claude 앱에서 그 세션을 직접 열어 봐도 몇 초 안에 알림이 저절로 지워집니다.
CPU·RAM 알림 글을 누르면 작업 관리자가 열립니다.

고양이를 클릭하면 폴짝 뛰고 상태 카드(CPU · RAM · 디스크 여유 · 배터리 · 일하는 Claude 세션 수)가 6초 동안 보입니다.
머리를 좌우로 문지르면 하트가 뜹니다. 끌어서 옮기면 매달렸다가 놓으면 떨어집니다.
모니터가 여러 대면 옆 모니터로 걸어가거나 끌어서 옮길 수 있고, 바닥이 낮은 모니터로 넘어가면 떨어져 착지합니다.
고양이와 말풍선 바깥은 클릭이 뒤 창으로 그대로 지나갑니다.

기준값(85% · 10초 · 90% · 5분)은 모두 가정이며 설정 창에서 바꿀 수 있습니다.

## 실행

```bash
npm install
npm start
```

`node_modules/electron/dist/electron.exe` 가 없다는 오류가 나면 Electron 본체 내려받기가 빠진 것입니다. `node node_modules/electron/install.js` 를 한 번 돌립니다.

검사는 `npm test` 로 돌립니다(대기열 · 훅 설치 · 세션 제목 · CPU·RAM 판정).

## Claude Code 연동

처음 실행하면 `~/.claude/settings.json` 에 훅 3개(`UserPromptSubmit` · `Stop` · `Notification`)를 더합니다.
훅은 받은 JSON 을 `http://127.0.0.1:47321/hook/<이벤트>` 로 넘기기만 합니다. 다른 설정과 사용자 훅은 그대로 둡니다.
설치 전 원래 파일은 `~/.claude/settings.json.pawtrol-backup` 에 남습니다.

- 펫이 꺼져 있으면 훅은 약 0.4초 안에 조용히 끝나고 Claude 작업을 막지 않습니다(윈도우 실측).
- 설정 창의 "제거"를 누르면 펫 훅만 빠지고, 그 뒤로는 자동으로 다시 넣지 않습니다.
- 세션 제목은 Claude 앱의 세션 파일(`%LOCALAPPDATA%\Claude-Data\…\claude-code-sessions\…\local_*.json`)에서 사이드바 제목을 읽습니다. 못 찾으면 기록 파일(transcript)의 마지막 `custom-title` 줄 → 작업 폴더 이름 순으로 씁니다.
- 세션 열기는 `claude://code/continue?session=local_…` 주소로 합니다. 세션 파일 위치와 이 주소는 Claude 앱 내부 구조라 앱이 바뀌면 동작하지 않을 수 있습니다. 그때도 알림 자체는 그대로 뜹니다.
- 훅 명령은 Git Bash 의 `curl` 로 돕니다.

개발 중에는 `PAWTROL_DEBUG=1` 로 실행하면 받은 훅과 화면 콘솔이 터미널에 찍힙니다.

## 그림

`src/renderer/sprite-cat.js` 가 고양이를 칸 단위로 찍습니다. 칸 기호(털 `f` · 무늬 `d` · 눈동자 `g` …)마다 색표에서 색을 찾으므로 색표만 바꾸면 전체 색이 바뀝니다.
